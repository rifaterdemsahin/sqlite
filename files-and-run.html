Every File in This Repository & What Is Needed to Run It

🌐 Local Port Policy: Port 30,000+ (30085)

3. What Is Needed to Run It (Step-by-Step Commands)

Choose any of the 4 ways below to run or deploy the sandbox:

Option A: Run CLI Verification Only (No Web Server)

Requires only Python 3 (built-in on macOS). Creates the `.db` file, runs the ACID crash test, copies the file, and writes `latest_benchmark.json`:

python3 sandbox.py --cli-only

Option B: Run Local Interactive Server (Port 30,000+)

Starts the local HTTP & SQLite API server on port 30085 and opens the pages in Google Chrome:

python3 sandbox.py --port 30085
open -a "Google Chrome" http://localhost:30085/index.html
open -a "Google Chrome" http://localhost:30085/architecture.html
open -a "Google Chrome" http://localhost:30085/files-and-run.html

Option C: Inspect the Single `.db` File Directly via SQLite CLI

Because the database is just an ordinary file on disk, you can open it directly with the `sqlite3` CLI or copy it with `cp`:

cp sandbox_data/ai_workflow_sandbox.db my_backup.db
sqlite3 sandbox_data/ai_workflow_sandbox.db "SELECT * FROM agent_runs;"

Option D: Deploy to Fly.io (Using Azure Key Vault Token)

Fetches `FLY-API-TOKEN` from Azure Key Vault `dp-kv-deliverypilot` and deploys to `https://sqlite-ai-sandbox.fly.dev`:

export FLY_API_TOKEN=$(az keyvault secret show \
  --vault-name dp-kv-deliverypilot \
  --name FLY-API-TOKEN --query "value" -o tsv)
fly deploy --ha=false
